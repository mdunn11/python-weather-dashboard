# Python Weather Dashboard

**Python Portfolio Project #2 | Technical Apprenticeship 3.0**

A Python portfolio project designed to retrieve real-world weather data through an API, process JSON responses, and display weather conditions and forecasts in an interactive dashboard.

**Project Status:** Planning and Setup

## Project Objectives

- Learn to retrieve live data using Python and HTTP requests.
- Understand and process JSON responses.
- Practice functions, dictionaries, validation, and error handling.
- Build an interactive weather dashboard.
- Strengthen GitHub documentation, testing, and deployment skills.

## Planned Features

- Search for weather by city.
- Display temperature, humidity, and wind conditions.
- Display a short-term weather forecast.
- Handle invalid locations and API errors.
- Present weather information using Streamlit.

## Planned Technologies

- **Python:** Application logic
- **Open-Meteo API:** Weather information
- **Requests:** API communication
- **Streamlit:** Interactive dashboard
- **GitHub:** Version control and documentation
